# config/

Archivos de configuración de ejemplo para integración probes (verificación de conectividad de servicios externos).

- `integration-probes.staging.example.json` — ejemplos de probes para staging (GraphQL, gRPC, SQL, REST)
- `integration-probes.prod.example.json` — idem para producción

Copiar sin el `.example` y completar con URLs y tokens reales. Los archivos reales NO se commitean (`.gitignore`).
