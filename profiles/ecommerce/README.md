# profiles/ecommerce

Perfil que activa el conjunto de módulos para e-commerce. Declara qué módulos, entidades y workflows están disponibles cuando un tenant usa este perfil.

Módulos incluidos: `orders`, `inventory`, `catalog`, `billing`, `ecommerce`. Entidades primarias: `Product`, `Order`, `Invoice`, `Stock`, `Customer`.

No contiene lógica — es una declaración de configuración.
